# java-lotto

로또 미션 저장소

### 👥 Pair

#### 조로(김건우), 윌슨(박형균)

## 📝 진행 과정

### 1. 사용자가 구입 금액을 입력 한다.

```text
구입금액을 입력해 주세요.
5000
```

- 구입 금액은 `1,000원` 단위여야 한다.
- 구입 금액의 최대는 `2,000,000,000원`으로 제한한다.

#### 예외 처리

- [X] 1,000원 단위의 자연수가 아닌 경우
- [X] 2,000,000,000원을 초과한 경우

### 2. 구매한 로또 목록을 출력 한다.

```text
5개를 구매했습니다.
[4, 14, 16, 30, 41, 43]
[7, 11, 14, 23, 26, 44]
[4, 5, 11, 32, 36, 40]
[12, 19, 22, 24, 28, 34]
[3, 9, 21, 22, 31, 34]
```

### 3. 지난주 당첨 번호를 입력 한다.

```text
지난 주 당첨 번호를 입력해 주세요.
1,2,3,4,5,6
```

- 1 ~ 45의 숫자를 `,`로 구분하여 6개 입력
- 당첨 번호는 중복 불가

#### 예외 처리

- [X] 숫자의 범위가 1 ~ 45를 벗어난 경우
- [X] 중복 숫자가 존재하는 경우
- [X] 숫자가 6개가 아닌 경우

### 4. 보너스 볼을 입력 한다.

```text
보너스 볼을 입력해 주세요.
7
```

- 1 ~ 45의 숫자를 1개 입력
- 당첨 번호와 중복 불가

#### 예외 처리

- [X] 숫자의 범위가 1 ~ 45를 벗어난 경우
- [X] 숫자가 당첨 번호와 중복 되는 경우
- [X] 숫자가 아닌 경우

### 5. 당첨 통계를 출력 한다.

```text
당첨 통계
---------
3개 일치 (5,000원) - 0개
4개 일치 (50,000원) - 0개
5개 일치 (1,500,000원) - 0개
5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
6개 일치 (2,000,000,000원) - 0개
총 수익률은 0.00입니다.(기준이 1이기 때문에 결과적으로 손해라는 의미임)
```

### 6. 예외 상황 시 `[ERROR]` 로 시작하는 에러 문구 출력
```text
구입금액을 입력해 주세요.
-1
[ERROR] 구입 금액은 1,000원 이상 2,000,000,000원 이하여야 합니다.
구입금액을 입력해 주세요.
```
- 예외가 발생한 부분 부터 재입력을 받는다.

## 📝 클래스 및 기능 구현 목록

### domain

#### Lotto

- [X] 로또 번호를 저장 한다
- [X] 특정 숫자가 로또 번호에 포함 되어 있는지 확인 한다

#### BonusNumber

- [X] 보너스 번호를 저장 한다

#### WinningNumber

- [X] 당첨 번호와 보너스 번호를 저장 한다

#### WinningResult

- [X] 당첨 번호와 로또들을 이용하여 당첨 결과를 계산 한다.

#### WinningProfit

- [X] 당첨 결과를 이용하여 총 당첨 긍액과 수익률을 계산 한다.

#### LottoRank(enum)

- [X] 로또 당첨 정보를 정의 한다

#### Money

- [X] 구입 금액을 저장

### exception

#### AppException

- [X] `IllegalArgumentException` 의 하위 클래스

#### ErrorMessage(enum)

- [X] 에러 메세지 정의

### util

#### RandomNumbersGenerator

- [X] NumberGenerator의 구현체
- [X] 1 ~ 45 사이의 난수 6개 생성

#### StringParser

- [X] 문자를 숫자로 변경
- [X] 문자를 구분자 기준으로 리스트로 변경

### controller

#### LottoController

- [X] 애플리케이샨을 제어 하는 클래스

### view

#### InputView

- [X] 사용자가 입력한 숫자를 읽음

#### OutputView

- [X] 사용자에게 로또 관련 데이터를 출력
